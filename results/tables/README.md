## What each must contain

**Section 4** asks explicitly for: total parameter count, estimated model size on disk (KB),
training time per epoch, and test accuracy. Add MACs — it is the number that actually demonstrates
the depthwise-separable saving.

**Section 3** asks for convergence *and* final performance. Report both: `best_val_acc` for
performance, and epochs to reach 90% of that run's own best validation accuracy for speed. They can
disagree, and that disagreement is worth discussing.

**Section 6** is the central table: trainable params, total params, size, MACs, CPU inference
latency, peak memory, test accuracy, macro precision and recall. State ratios, not just both
numbers — "40x fewer parameters for 6 points of accuracy" is an argument; two columns of figures
is not.
